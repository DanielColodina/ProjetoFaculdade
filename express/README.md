# Express sample

Instruções rápidas:

1. Instalar dependências:

```
cd /d "c:\Users\danie\OneDrive\Área de Trabalho\MARCOSWesley\express"
npm install
```

2. Rodar em desenvolvimento (reinicia automático quando mudar arquivos):

```
npm run dev
```

3. Rodar em produção:

```
npm start
```

Se `nodemon` não estiver instalado localmente, instale com:

```
npm install --save-dev nodemon
```
